Website Institucional - Guardiões do Templo Nº 3544

Este repositório contém o código-fonte da página principal (Landing Page) da Loja Maçônica Guardiões do Templo Nº 3544. O projeto foi desenvolvido utilizando tecnologias web padrão para criar uma interface solene e funcional.

🎨 Design e Interface

O site foi projetado para oferecer uma experiência visual imersiva e informativa:

Background Imersivo: Utiliza uma imagem em alta definição (arca.jpg) configurada com background-size: cover para preencher toda a tela de forma responsiva.

Identidade Visual: O cabeçalho apresenta o logotipo oficial da loja, com efeitos de sombra (drop-shadow) para destaque visual.

Legibilidade: Aplicação de text-shadow em títulos e links para garantir o contraste contra a imagem de fundo.

Navegação: Menu intuitivo com efeito de hover semitransparente, facilitando o acesso às seções de história, galeria e intranet.

🛠️ Tecnologias Utilizadas

HTML5: Estruturação semântica do conteúdo (header, nav, main, footer).

CSS3: Estilização interna, incluindo:

Flexbox: Para o alinhamento dinâmico da logo e do menu de navegação.

Posicionamento Absoluto: Utilizado na estrutura de menus suspensos (dropdowns).

Estilização Responsiva: Configurações de min-height e centralização de background.
